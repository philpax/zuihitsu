Methods are written `<memory>:method(...)`, where `<memory>` stands for a memory handle you hold — the result of `memory.create` or `memory.get`. Call the method directly on that handle: e.g. with `local m = memory.get("{{person}}...")`, write `m:append("...")` (not `m:<memory>:append(...)`). The `memory.*`, `tags.*`, `links.*`, `calendar.*`, `context.*`, and `block.*` calls are module functions, called with a dot.
