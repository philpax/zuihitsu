table.concat joins only strings and numbers, but this list holds values it cannot — a handle list like mem:entries() or hub:links(), most likely. To see the list, print(list) already renders each handle on its own line — no join needed. To compose text from handles, interpolate one into a backtick string — `latest: {es[1]}` renders it as its text — or, since a handle concatenates directly ("- " .. e renders one), build the string with .. in a loop.
