occurred_at does not name an occurrence ({{got}}). Pass a bare "YYYY-MM-DD" string or a date object (calendar.today(), calendar.date("…")) for a single day, or a tagged table for a richer occurrence: { day = "YYYY-MM-DD" }, { instant = <epoch ms> }, { range = { start = …, ["end"] = … } }, { approx = { center = …, fuzz_days = N } }, { recurring = "FREQ=WEEKLY" }, or { before_after = { dir = "before" | "after", anchor = "<memory name>" } }
