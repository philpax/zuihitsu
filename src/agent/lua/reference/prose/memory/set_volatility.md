Set a memory's volatility — how fast its facts drift. "high" for fast-changing facts (a current role, where someone is, what they are working on), "medium" the default, "low" for durable facts like a name. A high-volatility memory surfaces later flagged `stale — no newer entry` once it ages out: possibly out of date with nothing to replace it, so hedge or reconfirm rather than hunting for a fresher version.
