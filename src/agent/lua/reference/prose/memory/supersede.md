Correct a fact in place: mark an old entry superseded by a new one on the same memory. Append the correction first to get the new entry object, then supersede with the old entry object (from <memory>:entries) and the new one. The old entry drops from live reads but stays in <memory>:history. Use this only when the same fact genuinely changed — a correction or an update (often a teller revising their own earlier statement). To withdraw a fact with no replacement — or to move one filed on the wrong memory — use <memory>:retract instead. For two participants' conflicting accounts, do not supersede one with the other: record both separately and leave the disagreement standing, to be reconciled rather than silently resolved to whoever spoke last.
