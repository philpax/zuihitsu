Fetch a memory by name, or create it if there is none — the fetch-or-make idiom in one call. It is for a name you have READ — off a search hit, a brief, or a handle — not one you guess: a name that does not match mints a fresh duplicate under the guessed name rather than finding the one you meant. So search first and pass a name you saw. If it exists it is returned as-is and the content argument ignored; only an absent one is created. Reserve memory.create for a deliberately new memory, where a collision should error. Not an identity tool: a new name for a person you already hold is a fact on their existing profile (or grounds for a rename) — get_or_create on it would mint a duplicate.
